🚵 Chatbot Widget — Cycling Week Barcelona

Este archivo contiene el código fuente completo y aislado del widget de chat.
El botón aparece en la esquina inferior derecha.

Para integrarlo en cualquier web, el cliente solo necesita pegar el bloque
<!-- CHATBOT WIDGET --> antes del </body> de su HTML.

Pasos para activar el chat:
1. Abre ⚙ Ajustes en el agente de correo y guarda tu API key
2. La clave se comparte automáticamente vía localStorage
3. Vuelve aquí y el chatbot ya estará operativo
4. En producción: reemplaza el localStorage por una llamada a tu backend
